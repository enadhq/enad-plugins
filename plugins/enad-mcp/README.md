# Enad

The Enad plugin connects your assistant to your Enad product catalog. Use it to look up product information, search the Enad documentation, and prepare catalog updates through your connected Enad app.

Sign in with your Enad account and select the app you want to connect. The tools can access the data and operations your connection permits. Catalog changes are previewed before they are applied, and your app settings determine when a separate approval is required.

Try asking “Use Enad to find the documentation on attribute templates” or “Show the first five products in my connected Enad app.”

[Installation and support](https://github.com/enadhq/enad-plugins#enad) · [Enad privacy policy](https://enad.io/legal/privacy-policy)

To install from Claude Code, run `/plugin install enad --marketplace enadhq/enad-plugins`.
